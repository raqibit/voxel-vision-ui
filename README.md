# Voxel Vision AI

A self-contained, responsive concept interface inspired by the supplied futuristic 3D landing-page reference.

## Run it

No build tools or dependencies are required.

1. Unzip the folder.
2. Open `index.html` in a modern browser.

For local development with live reload, you can also use any static web server, for example the Live Server extension in VS Code.

## Included

- Responsive desktop, tablet, and mobile layouts
- Animated interactive 3D-style canvas form
- Working section navigation and mobile menu
- Dark/light appearance control
- Play/pause animation control
- Testimonial carousel
- Scroll-reveal animation with reduced-motion support
- Accessible labels and keyboard focus states

## Files

- `index.html` — page structure and content
- `styles.css` — complete visual design and responsive layout
- `script.js` — canvas renderer and interactions

All visual assets are generated with CSS and JavaScript, so the project works offline.
